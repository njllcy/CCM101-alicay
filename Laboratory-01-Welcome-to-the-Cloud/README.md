# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced the basic concepts of working in a Linux environment using the KillerCoda Playground. The mission focused on creating a Linux user account, exploring the operating system, organizing files and folders, documenting system information, and setting up a professional GitHub repository to serve as a Cloud Computing Portfolio.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed

- Launched an Ubuntu Linux environment in KillerCoda.
- Created a new Linux user with a home directory and sudo privileges.
- Collected system information, including Linux distribution, kernel version, CPU, memory, and disk space.
- Created folders and Markdown files for documentation.
- Built a Cloud Computing Portfolio repository on GitHub.
- Uploaded laboratory files and screenshots to the repository.

## Skills Learned

- Basic Linux command-line navigation.
- User account creation and management.
- Collecting system information in Linux.
- Creating and organizing directories and files.
- Writing documentation using Markdown.
- Organizing and maintaining a GitHub repository.
