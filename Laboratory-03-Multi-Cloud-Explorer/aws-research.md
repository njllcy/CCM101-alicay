# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers many services that businesses and developers can use to run applications, store data, manage networks, and build cloud systems.

## Global Infrastructure

AWS has data centers around the world. These are organized into Regions and Availability Zones. Regions are different geographic areas, while Availability Zones are separate locations inside a Region. This helps businesses run their applications in different locations and improve reliability.

## Cloud Management Console

The AWS Management Console is a website where users can manage their AWS services and resources. Users can create and manage virtual machines, storage, databases, networks, and other cloud services through the console.

## Four Core Services

1. **Amazon EC2** – Provides virtual servers that can be used to run applications and websites.

2. **Amazon S3** – Provides storage for files, images, videos, backups, and other types of data.

3. **Amazon RDS** – Provides managed relational databases, making it easier to create and manage databases.

4. **Amazon VPC** – Provides a private virtual network where users can securely run their AWS resources.

## Three Advantages

1. **Scalability** – AWS allows businesses to increase or decrease their resources based on their needs.

2. **Global Infrastructure** – AWS has cloud infrastructure in many parts of the world, allowing businesses to serve users from different locations.

3. **Broad Range of Services** – AWS offers many different services for computing, storage, databases, networking, security, analytics, and other cloud needs.

## Typical Enterprise Use Cases

- Hosting websites and business applications
- Storing and backing up company data
- Hosting databases
- Running e-commerce applications
