# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud platform provided by Google. It offers different services that businesses and developers can use to store data, run applications, manage websites, and build cloud-based systems.

## Global Infrastructure

Google Cloud has data centers in different parts of the world. These locations are organized into regions and zones. This allows users to run their applications closer to their customers and helps keep services available.

## Cloud Management Console

Google Cloud Console is a web-based tool used to manage Google Cloud resources. Users can create and manage virtual machines, storage, databases, networks, and other cloud services through the console.

## Four Core Services

1. **Compute Engine** – Provides virtual machines for running applications and workloads.
2. **Cloud Storage** – Stores files, images, videos, backups, and other data.
3. **Cloud SQL** – Provides managed SQL databases.
4. **Google Kubernetes Engine (GKE)** – Allows users to run and manage containerized applications using Kubernetes.

## Three Advantages

1. **Strong AI and Machine Learning** – Google Cloud provides many tools for developing and running AI and machine learning applications.
2. **Good Kubernetes Support** – GCP provides Google Kubernetes Engine (GKE), which makes it easier to run and manage Kubernetes applications.
3. **Global Network** – Google has a large global network that helps provide fast and reliable cloud services.

## Typical Enterprise Use Cases

- Hosting websites and applications
- Storing and managing large amounts of data
- Artificial Intelligence and Machine Learning
- Running containerized applications
- Data analytics
- Backup and disaster recovery
