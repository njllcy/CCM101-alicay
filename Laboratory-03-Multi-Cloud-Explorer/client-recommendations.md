# Cloud Platform Recommendation 

## Client A – Startup Company

A startup company wants to launch a new mobile application. Their budget is limited, but they expect rapid growth within the next few years.

### Recommended Platform: AWS

AWS is a good choice for the startup because it offers many services that can support a growing mobile application. The startup can start with the resources it needs and increase them as the number of users grows. AWS also has flexible pricing options that can help the company manage its budget. The startup could use Amazon EC2 for computing, Amazon S3 for storing files, and Amazon RDS for its database.

### Services

- Amazon EC2
- Amazon S3
- Amazon RDS

## Client B – University

A university already uses:

- Windows Server
- Microsoft 365
- Active Directory

The university wants to migrate some services to the cloud.

### Recommended Platform: Microsoft Azure

Microsoft Azure is the best choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure works well with Microsoft technologies, making it easier to connect existing systems to cloud services. This can make the migration easier for the university's IT staff. The university could use Azure Virtual Machines, Microsoft Entra ID, and Azure SQL Database.

### Services

- Azure Virtual Machines
- Microsoft Entra ID
- Azure SQL Database

## Client C – AI Research Company

A research company develops Artificial Intelligence and Machine Learning applications that require high-performance computing.

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud is a strong choice for the AI research company because it provides many tools for Artificial Intelligence and Machine Learning. It also provides computing resources that can be used for demanding workloads. The company can use these services to develop, train, and run AI applications. Useful services include Compute Engine, Google Kubernetes Engine (GKE), and Vertex AI.

### Services

- Compute Engine
- Google Kubernetes Engine (GKE)
- Vertex AI

## Client D – Global E-Commerce Company

A multinational online shopping company serves customers around the world and requires highly available infrastructure with automatic scaling.

### Recommended Platform: AWS

AWS is a suitable choice for the global e-commerce company because it has a large global infrastructure and services that support highly available applications. The company can use automatic scaling to handle changes in customer traffic. AWS can also help the company store data and distribute its application to users in different locations. Useful services include Amazon EC2, Elastic Load Balancing, and Amazon S3.

### Services

- Amazon EC2
- Elastic Load Balancing
- Amazon S3

## Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | AWS offers many services and flexible options that can support a startup as it grows. |
| Enterprise Organization | AWS | AWS provides many services and a large global infrastructure for enterprise workloads. |
| Microsoft Environment | Microsoft Azure | Azure works well with Windows Server, Microsoft 365, and Microsoft Entra ID. |
| AI / Machine Learning | Google Cloud Platform (GCP) | GCP provides strong AI and Machine Learning tools for developing and running AI applications. |
| Kubernetes Deployment | Google Cloud Platform (GCP) | GCP provides Google Kubernetes Engine (GKE), which makes it easier to manage Kubernetes applications. |
| Global Web Application | AWS | AWS has global infrastructure and services that can support highly available web applications. |
