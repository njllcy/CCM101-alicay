# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides a wide range of services that organizations can use to build, deploy, manage, and scale applications and IT infrastructure in the cloud.

## Global Infrastructure

Azure has a global infrastructure organized into geographic regions. Azure regions contain datacenters and networking infrastructure, and many regions provide Availability Zones for redundancy and fault isolation. Azure currently provides more than 70 regions globally.

## Cloud Management Console

The Azure portal is a web-based management console used to create, manage, and monitor Azure resources. Users can manage services such as virtual machines, databases, storage, networking, and other cloud resources through its graphical interface.

## Four Core Services

1. Azure Virtual Machines – Provides virtual machines for running applications and workloads.
2. Azure Blob Storage – Provides object storage for unstructured data such as files, images, and videos.
3. Azure SQL Database – Provides a managed relational database service.
4. Azure Virtual Network – Provides private networking for Azure resources.

## Three Advantages

1. Microsoft Integration – Azure works well with Microsoft technologies such as Windows Server, Microsoft 365, and Microsoft Entra ID.
2. Global Infrastructure – Azure provides a broad global infrastructure that supports applications in different geographic locations.
3. Enterprise Capabilities – Azure provides services for security, identity, networking, databases, analytics, and application development.

## Typical Enterprise Use Cases

- Migrating Windows Server workloads to the cloud
- Hosting enterprise applications
- Cloud-based databases
- Microsoft 365 and identity integration
- Web application hosting
- Data analytics and artificial intelligence
